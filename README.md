# BEM-VINDOS AO IN AMERICA'S STYLE!

Este projeto de site está sendo construído em _.HTML_ e _.CSS_ como parte das atividades práticas de número _6_ do treinamento de programação **_Zuplae 2025_**, e tem como objetivo informar aos leitores e amantes das Américas curiosidades sobre os três continentes americanos: **_América do Sul, América Central e América do Norte_**. Separadas por regiões, essas informações abrangem a lista completa de todos os países, o Índice de Desenvolvimento Humano e Renda Per Capita, a quantidade total de habitantes e suas cidades mais populosas, além de trazer um ranking com as médias salariais dos profissionais de TI no mercado ocidental.


## Estrutura do Site

Este site possui uma página principal com estrutura em **_.HTML5_** contendo as informações relacionadas ao sistema. A página principal possui:
> Um cabeçalho contendo a **_logo_** e o título **_title_** do site;
> Um rodapé **_footer_** com as informações de direitos autorais;
> Possui também 4 opções de **_menu_** que redirecionam para páginas com cada uma das informações abordadas no site:

|                |América do Norte |América Central | América do Sul
|----------------|-----------------|----------------|-------------------|
|Lista de Países|            |            |
|IDH / Renda Per Capita          |            |            |
|População          |||
|Média Salariais TI          || |

- Cada uma das sub-páginas do sistema também foram construídas em **_.HTML5_** e todas foram estilizadas utilizando a folha de estilos **_.CSS_**, elas possuem o mesmo cabeçalho e rodapé da página principal. E também fazem uso das estruturas de:

	> **_Lista não ordenada .ul_**, **_Lista ordenada .ol_**, **_links de redirecionamento para páginas .a_**, **_menus de navegação como **Nav**  e **Div**_**, tags e propriedades como display **_flex_** e **_block_**, negrito **_bold_**, linha **_hr_**, salto de linha **_br_**, **_background_**, **_color_**, entre outros.



## Tecnologias Abordadas:

- Para este projeto foram estudados Conceitos de Github, repositórios, VSCode, HTML, CSS, linguagem de markdown, plugins como Live Server. E suas interações, commits, pull request, divisão em branchs, modelo kanban, organização de pastas.
